# PREVI MATCH | PREVIPAULISTA (PREVICHECK)

Sistema Inteligente de Conferência, Batimento e Auditoria de Dados Previdenciários (RPPS Paulista/PE).

## Funcionalidades Principais
- **Batimento Inteligente (PROCV/PROCX):** Cruzamento exato e aproximado (Levenshtein) de CPF, nomes, matrículas, datas e valores em lotes assíncronos.
- **Integração CADPREV:** Canal institucional seguro e consulta individual rastreada.
- **Painel Analítico & Exportação:** Relatórios em Excel (`.xlsx`), PDF oficial e envio integrado via Gmail.
- **Gestão de Acessos RBAC:** Painel exclusivo do Administrador Master (`GUILHERME ALESANDER MELO DE SOUZA`).

## Como Executar
Abra o arquivo `index.html` diretamente em qualquer navegador moderno ou publique via **Render Static Site** / **GitHub Pages**.

## Deploy no Render (Blueprint Automático)
1. Acesse [dashboard.render.com](https://dashboard.render.com) > **New +** > **Static Site** (ou **Blueprint**).
2. Conecte o repositório `guilhermealesander/PREVICHECK`.
3. Publish Directory: `.` (raiz).
